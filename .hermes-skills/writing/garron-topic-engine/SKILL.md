# 选题引擎 (Topic Engine)

写作的第一步不是「怎么写」，而是「写什么」。本 skill 帮助从多个来源发现话题，用世界观框架评估质量，输出可执行的选题池。

**触发时机：** 用户说「不知道写什么」「帮我选题」「有什么可以写的」「想写但没灵感」时加载。

**后续衔接：** 选题确定后 → 加载 `garron-insights-deepdive` 做洞察挖掘 → 加载 `garron-writing-style` 写作。

---

## 阶段 1：素材扫描（Knowledge Collector）

从三个来源自动扫描潜在话题：

### 1.1 flomo 笔记扫描

- 路径：`/mnt/c/Users/37840/Desktop/Garron/flomo@Garron-20260430/`
- 搜索策略：
  - 最近 7 天的笔记（时效性）
  - 带「？」的笔记（未解决的问题 = 潜在选题）
  - 被反复提及的关键词（高频主题）
  - 带强烈情绪的笔记（愤怒/兴奋/困惑 = 有话要说）
- 输出：5-10 条候选话题，附原始笔记引用

### 1.2 个人经历回溯

基于 `references/personal-profile.md`，检查最近的生活阶段是否有未写过的素材：
- 最近的工作/实习中有什么观察？
- 最近的义工经历中有什么故事？
- 最近的对话/争论中有什么触发点？
- 最近读了什么书/文章/播客有共鸣或反对？

### 1.3 热点事件匹配

如果用户提到最近关注的事件/新闻，用世界观框架快速定位角度：

| | 游戏 | 无障碍 | 可持续 |
|---|---|---|---|
| **宏观** | 这个事件的「规则」是谁定的？ | 谁被排除在讨论之外？ | 它的影响能持续多久？ |
| **中观** | 相关组织的激励机制对吗？ | 谁在这个事件中没有话语权？ | 制度/文化能自我修复吗？ |
| **微观** | 这对「我的游戏」有什么启示？ | 我给自己设了什么隐形门槛？ | 我的选择十年后还成立吗？ |

## 阶段 2：话题衍生（Topic Generator）

对每个候选话题，生成 2-3 个不同角度的切入方式：

### 角度生成模板

拿到一个话题 X，问自己：

1. **反直觉角度**：大多数人对 X 的看法是什么？反过来想呢？
   - 例：「Agent 提高效率」→「Agent 暴露了我假装在工作」
2. **个人体感角度**：我在 X 中真正感受到了什么？不是「应该感受什么」
   - 例：「公益咨询」→「服务志愿者的志愿者」
3. **结构分析角度**：X 背后的游戏规则/权力关系/激励机制是什么？
   - 例：「无障碍」→「谁被排除在数字社会之外？」
4. **代价反思角度**：X 的好处大家都说了，代价呢？谁在承担？
   - 例：「AI 写作」→「手感的消亡：隐性知识会被蚕食吗？」
5. **跨界连接角度**：X 跟我的另一个关注领域（游戏/公益/管理）有什么关系？
   - 例：「加密通讯」×「游戏视角」→「感受力是你还拥有选择权的证据」

### 输出格式

每个话题输出：
```
📌 话题：[一句话描述]
🎯 角度 A：[反直觉切入]
🎯 角度 B：[个人体感切入]
🎯 角度 C：[结构分析切入]
📐 世界观坐标：[三视角×三层次定位]
⚡ 能量评估：[你对这个话题有多少话想说？1-5]
```

## 阶段 3：选题评估（Topic Scoring）

用以下维度给每个候选话题打分（1-5 分）：

| 维度 | 问题 | 权重 |
|------|------|------|
| **体感强度** | 你真正经历过/感受过吗？ | ×3 |
| **非共识度** | 这个观点大家会争论还是会点赞？ | ×2 |
| **信息增量** | 你能提供别人没有的视角或数据吗？ | ×2 |
| **受众匹配** | 你的目标读者会在意这个话题吗？ | ×1 |
| **时机** | 现在写比以后写更有价值吗？ | ×1 |

**总分 = 各项×权重之和**，满分 45 分。

**筛选规则：**
- 30+ 分：立即写
- 20-29 分：放入选题池，等时机
- 20 分以下：存档，不急

## 阶段 4：选题池管理

### 选题池文件

存放在 Obsidian：`ClawVault/选题池.md`

```yaml
---
title: 选题池
category: 写作管理
tags: [选题, 内容策略]
---
```

格式：
```
## 待写（30+ 分）
| 话题 | 角度 | 坐标 | 分数 | 状态 |
|------|------|------|------|------|

## 储备（20-29 分）
| 话题 | 角度 | 坐标 | 分数 | 状态 |
|------|------|------|------|------|

## 已完成
| 话题 | 文章链接 | 完成日期 |
|------|---------|---------|
```

### 状态流转

```
灵感 → 待评估 → 待写 → 写作中 → 已完成
                    ↘ 储备 → 待写（时机到了）
```

```

3. 对某个话题换个角度再展开
4. 手动补充一个你想写的话题
```
