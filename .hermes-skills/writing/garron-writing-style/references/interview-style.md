# 采访写作风格参考：「顺势而为，对错在心」

> 来源：专访陈宽语 PDF（13 页杂志采访）

## 结构模板

```
1. 热点/争议引入（最近发生了什么，制造悬念）
2. 当事人回应（直接引语，展现态度）
3. 金句提炼（一句核心引语独立成段，加粗或引用格式）
4. 背景回溯（非典型成长史，从小透明到转折点）
5. 挑战与低谷（批评声、自我怀疑、艰难选择）
6. 细节呈现（角色/作品的具体细节，有画面感）
7. 第三方评价（导演/评论人/同事的引语，多视角印证）
8. 商业/社会维度分析（争议如何转化为价值）
9. 结尾升华（当事人自己的哲学表达，回扣标题）
```

## 语言特征

- **第三人称叙事**：作者是隐形的观察者，不插入个人观点
- **引语驱动**：核心论点通过当事人和第三方的直接引语呈现，而非作者概括
- **细节具象化**：「开会时下意识转笔的小动作」「深夜独处时眼神瞬间的放空」
- **反差叙事**：「越被骂，越红火」「不降反升」「不完美反而成了稀缺吸引力」
- **标题金句化**：「顺势而为，对错在心」本身就是文章的核心哲学
- **编号段落**：每段有编号，适合杂志排版，信息密度高

## 与 Garron 风格的差异

| 维度 | Garron 风格 | 采访风格 |
|------|-----------|---------|
| 视角 | 第一人称「我」 | 第三人称观察 |
| 核心驱动力 | 个人体验 → 框架分析 | 当事人引语 → 多方印证 |
| 情感表达 | 直接表达（思辨、自嘲） | 通过引语和细节间接呈现 |
| 结构 | ✏️正文 → ☀️动态 → ☉️金句 | 编号段落，线性推进 |
| 论证方式 | 框架+类比+个人故事 | 引语+细节+第三方评价 |

## 可借鉴的技巧

1. **引语驱动论证**：与其自己说「XX 很重要」，不如引用一个真正说过这句话的人
2. **反差标题**：标题本身就是一个待解释的悖论（「越被骂越红火」）
3. **细节画面感**：「下意识转笔」「眼神瞬间放空」比「她很努力」有力 100 倍
4. **多方印证**：同一观点，当事人说一遍、导演说一遍、评论人说一遍——可信度叠加
5. **结尾回扣标题**：文章最后，当事人用自己的话重新诠释标题，完成闭环
