# 人生主题框架

## 三个视角

- 🎮 **游戏的视角** — 机制设计、规则理解、玩家行为、系统反馈
- ♿ **无障碍的视角** — 谁被排除在外？如何降低参与门槛？包容性设计
- ♻️ **可持续的视角** — 长期主义、资源循环、不可逆后果、代际责任

## 三个层次

| 层次 | 关注点 |
|------|--------|
| 宏观 | 社会结构创新（制度、政策、技术范式、权力关系） |
| 中观 | 组织机制管理（团队、流程、激励、文化、治理） |
| 微观 | 人生系统设计（习惯、决策、身份、意义、能量管理） |

## 核心等式

> **管理 = 机制 ≈ 游戏** — 路江涌

管理的本质是设计机制，机制设计的核心逻辑与游戏设计同构：
- 规则（什么能做、什么不能做）
- 反馈（做了之后发生什么）
- 动力（为什么想做）
- 平衡（如何防止系统崩溃）

## 写作应用

拿到任何话题，问自己：
1. 它的「游戏规则」是什么？谁设计的？谁受益？（游戏视角）
2. 谁被挡在门外？门槛在哪？（无障碍视角）
3. 它能持续吗？代价由谁承担？（可持续视角）
4. 这是结构问题、组织问题，还是个人问题？（层次定位）
