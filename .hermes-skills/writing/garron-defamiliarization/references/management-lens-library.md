# Management Lens Library

用于 STS 陌生化的管理学 Lens。先匹配机制，再选择理论；不得因为理论名称新鲜就硬套。

| Lens | 最适合解释 | 典型机制 | 常见陌生化方向 |
|---|---|---|---|
| 信号理论 | 信任、品牌、专家背书、求职、内容可信度 | 信息不对称 → 可观察信号 → 信号成本/可信度 → 接收者判断 | “真正稀缺的不是信息，而是可信信号” |
| 资源基础观 RBV | 个人/组织为什么能形成长期优势 | 稀缺、难模仿、难替代资源 + 组织利用 | “你缺的可能不是努力，而是不可复制资产” |
| 资源依赖理论 | 为什么被平台、老板、渠道、供应商牵制 | 关键资源外部依赖 → 权力不对称 → 降低依赖 | “谁掌握你无法替代的资源，谁就掌握规则” |
| 生态系统理论 | 平台、医疗网络、合作伙伴、AI 工具链 | 互补品 + 接口 + 共同演化 | “竞争可能发生在生态位，不发生在单个产品” |
| 制度理论 | 为什么大家最后做得越来越像 | 规制/规范/认知压力 → 合法性 → 组织趋同 | “很多最佳实践只是合法性竞争” |
| 制度创业 | 新模式如何改变旧规则 | 资源 + 叙事 + 联盟 + 时机 → 制度改变 | “改变规则的人先改变大家理解问题的语言” |
| 悖论理论 | 两个互相矛盾的目标为何都不能放弃 | 对立目标长期共存 → 动态平衡 | “成熟不是二选一，而是长期承受矛盾” |
| 利益相关者理论 | 多方利益冲突 | 多主体诉求 → 权衡/共创 → 合法性 | “一个方案的阻力，往往来自被遗漏的利益相关者” |
| 社会交换理论 | 人为什么愿意额外付出或突然收缩 | 公平/支持 → 互惠 → 义务感 → 投入 | “关系一旦变成单向提款，额外付出会消失” |
| 组织支持理论 | 为什么员工觉得组织值不值得投入 | 被重视感 → 承诺/留任/绩效 | “员工不是只算工资，也在判断组织有没有站在自己这边” |
| 自我决定理论 SDT | 为什么有的人越管越没动力 | 自主 + 胜任 + 关系 → 内在动机 | “动力不是加奖励，而是减少被控制感” |
| 资源保存理论 COR | 倦怠、摆烂、回避、恢复 | 资源损失 → 防御性资源保全 → 减少投入 | “你以为是摆烂，可能是资源保全模式” |
| JD-R | 为什么工作让人耗竭或投入 | 工作需求消耗 vs 工作资源补给 | “忙不是问题，长期只有需求没有资源才是” |
| 社会资本理论 | 人脉、知识共享、职业机会 | 网络结构 + 信任 + 共同语言 → 资源流动 | “关系的价值不在认识多少人，而在资源能不能流动” |
| 心理所有权理论 | 为什么有人把项目当自己的 | 控制感 + 投入 + 熟悉 → 所有感 → 主动负责 | “真正的主人翁意识不是喊出来的，是参与权换来的” |
| 高阶理论 | 为什么不同领导带出完全不同组织 | 高管经历/认知/价值观 → 战略选择 | “公司的战略有时是管理层认知边界的投影” |
| UTAUT | 用户为什么愿意/不愿意用新技术 | 有用性 + 易用性 + 社会影响 + 便利条件 → 采纳 | “技术好不好，不等于用户会不会用” |
| TPB / TRA | 为什么知道道理却不行动 | 态度 + 主观规范 + 控制感 → 行为意图 → 行为 | “改变认知不一定改变行为，执行条件也在投票” |
| Flow | 为什么有些产品让人持续沉浸 | 挑战-能力匹配 + 即时反馈 + 专注 | “留存不是奖励堆出来的，是反馈节奏设计出来的” |
| CCT | 为什么消费会变成身份表达 | 商品符号 + 社群 + 身份叙事 | “很多消费买的不是功能，是一个可被别人识别的自己” |
| 自我概念维持 | 为什么好人也会小幅作弊 | 获利欲望 vs 道德自我形象 → 可容忍模糊空间 | “人不是在诚实和作弊之间选，而是在给自己找可接受的解释” |

## 使用原则

1. 先写现实机制 `A → B → C`。
2. 再找理论中与 A/B/C 对应的构念。
3. 至少有两个明确映射点才允许使用。
4. 理论只能提供解释骨架，不能替代事实证据。
5. 类比只能作为表达，不得冒充因果证明。
6. 高风险领域优先事实准确，陌生感次之。

## 常见组合

- 职场倦怠：`COR + JD-R + 社会交换/组织支持`
- AI 产品采纳：`UTAUT + TPB + Flow`
- 平台/个人 IP：`信号理论 + CCT + 社会资本`
- 创业与组织优势：`RBV + 资源依赖 + 生态系统 + 信号理论`
- 医疗运营：`利益相关者 + 制度理论 + 资源依赖 + JD-R + UTAUT`
