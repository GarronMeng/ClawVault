# STS 陌生化引擎

陌生化不是换高级词，也不是给普通常识套一个冷门理论名。

目标是找到不同领域之间真实存在的**机制同构**，让读者产生：

> “这个说法我第一次听，但仔细想想，好像真的是这样。”

核心链路：

```text
熟悉命题
  → 去包装
    → 底层机制 A→B→C
      → 5+ 跨学科 Lens 扫描
        → 同构测试
          → 陌生表达
            → 白话回译
              → 真实经历 / 数据
                → 边界校验
```

## 1. 原命题还原

先用一句最普通的话说明：这件事本来在说什么？

要求：不带术语、不带修辞、不抢着起标题。

## 2. 底层机制

必须先形成 `A → B → C`，再找理论。

优先检查：
- 资源损耗 / 补充；
- 激励错配；
- 信息不对称；
- 身份与规范；
- 权力依赖；
- 反馈回路；
- 阈值效应；
- 网络扩散；
- 路径依赖；
- 供需稀缺；
- 冗余与韧性；
- 注意力竞争；
- 风险转移；
- 选择压力。

如果机制说不清，不进入陌生化。

## 3. Lens Scan

至少扫描 5 个候选 Lens，最终只保留 1–2 个真正同构的。

优先顺序：
1. `references/management-lens-library.md`；
2. 经济学 / 心理学 / 社会学；
3. 生物学 / 生态学 / 进化论；
4. 控制论 / 信息论 / 网络科学；
5. 工程 / 建筑 / 城市规划 / 计算机科学。

## 4. 同构测试

每个 Lens 必须回答：
1. 现实中的 X 对应理论里的什么？
2. 至少能否找到两个明确映射点？
3. 理论解释的是机制，还是只有修辞相似？
4. 去掉理论名称后，逻辑还成立吗？

任何一项明显失败，淘汰。

## 5. 陌生化评分

内部按四项判断：

`陌生度 × 解释力 × 准确度 × 可讲述性`

优先选择“听起来陌生，解释完却非常直观”的 Lens，而不是最冷门的 Lens。

## 6. 输出三层表达

### 稳妥版
清晰、可信、不过度包装。

### 传播版
默认推荐。陌生感足够，但仍然能快速回译成白话。

### 强钩子版
允许创造表达性命名，但必须明确这是内容表达，不得冒充正式理论。

## 7. 回到真实世界

理论只负责骨架，内容的“肉”优先来自：
- Garron 的亲历；
- 工作项目；
- 公益现场；
- 数据；
- 失败；
- 对话；
- 长期观察。

当前上下文没有材料时，写 `[需要补真实材料]`，禁止自动编造第一人称经历。

## 8. 默认内容骨架

```text
Hook
  → Reality
    → Mechanism
      → Story
        → Insight
          → Boundary
```

## 9. Hard Rules

- 不用“熵增定律”解释一切；
- 不随机挑学科硬套；
- 不把隐喻写成科学因果；
- 不给普通常识发明学术味名字；
- 不虚构研究、百分比和案例；
- 不虚构 Garron 的经历；
- 医疗、金融、公共政策等高风险领域，陌生表达不得改变事实边界；
- 最终价值必须来自真实机制、真实经历或新的因果解释。

## 10. Default Output

```text
原命题：
底层机制：A → B → C
最佳 Lens：
映射点：
陌生表达：稳妥版 / 传播版 / 强钩子版
白话回译：
可调用真实材料：
内容骨架：
边界：
```
