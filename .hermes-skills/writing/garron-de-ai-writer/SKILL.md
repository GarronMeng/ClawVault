# De-AI Writer（Garron 版）

写完文章后的「去油」工序。在四层自检（L1-L4）之后、存档之前执行。

**触发时机：** 初稿写完 → 自检通过 → 去 AI 味 → 存档

---

## 执行方式

1. 读取完整文章
2. 按下方规则逐项扫描并改写
3. 直接输出改写后的完整文档
4. **不附加任何说明、不展示修改日志**

---

## 改写规则（按优先级执行）

### 1. 禁用词扫描（硬性）

以下词/句式出现即改，没有例外：

| 绝对禁用 | 替代方案 |
|---------|---------|
| 总而言之、综上所述、让我们 | 直接写结论 |
| 毋庸置疑、不言而喻、显而易见 | 删掉 |
| 以X为例、值得注意的是 | 直接进故事或重点 |
| 不仅…而且…、一方面…另一方面… | 换成「但」「而」「问题是」 |
| 在当今社会、随着科技发展 | 删掉，直接进主题 |
| 变得日益、已不再是…而是… | 「越来越」「不只是」 |
| 某种程度上、从某种角度来说 | 删掉，敢说就直说 |
| 打破了传统、重新定义了 | 用具体描述替代 |
| 这不仅仅是X，更是Y | 删掉，只保留更有信息量的那半句 |
| 值得注意的是 | 删掉，如果后面真有值得注意的内容，直接写 |
| 从某种意义上说 | 删掉 |
| 可以说是、可谓是 | 后面没有具体判断就删 |

### 2. 英文备注清理

**坚决删除画蛇添足的英文备注。**

- ❌ 「情感麻木（emotional numbing），是长期压力下的自我保护机制」
- ✅ 「情感麻木，是长期压力下的自我保护机制」
- 规则：首次出现的术语，中文即可。只有当英文原文对理解**不可或缺**时才保留（如专有名词、缩写 MCP/A2A）
- **绝不在括号里加英文翻译**，除非读者真的需要搜这个英文才能找到更多资料

### 3. 套路句式检查

以下结构出现即改：

- **自问自答套路化**：「为什么会这样？其实很简单……」→ 如果真有洞察就保留，如果只是换个说法重复就删
- **排比为排比而排比**：三段排比中如果有一段没有信息增量，砍掉
- **「这让我想起了……」**：如果后面接的是众所周知的理论（如德鲁克、海马体研究），考虑换一个更个人化的引入
- **每段都以「所以」「因此」「换句话说」开头**：删掉连接词，让逻辑自然流淌

### 4. 信息密度检查

每句话必须承担至少一种功能：提供信息 / 推进推理 / 限定条件 / 补充例外 / 解释因果。

**空转句示例（删）：**
- 「这让我想起了管理学里的一个经典区分。」→ 直接说区分是什么
- 「当然，我不是在鼓吹 XX。」→ 如果后文有转折，不需要这句话铺垫

**有信息量的示例（留）：**
- 「Agent 帮我在 20 分钟内跑完了过去需要两天的桌面研究。」
- 「一个视障大学生为了完成一份课程作业，要在读屏软件和网页不兼容的缝隙里多花 3 个小时。」

### 5. 标点节奏修正

- **破折号（——）**：不要用它制造节奏或强调。改为句号断句，或用逗号
- **感叹号**：全文最多 1-2 个，且只用在真正需要情绪爆发的地方
- **括号**：不要滥用括号插入解释。如果括号里的内容重要，就写进正文；如果不重要，删掉
- **引号**：不要用引号给普通词「加重点号」。只在引用原文或反讽时使用

### 6. 段落结构检查

- 段落开头就给出该段核心意思，不绕
- 相邻段落之间有自然承接，不硬切话题
- 长段落后必须有短句独立成段（制造断裂感），但短句不能太频繁（最多 500 字一次）

### 7. 语感终审

全文默读一遍，检查：

- **主语重复**：连续多句以「我」「它」「这」开头 → 换主语或合并
- **名词化过度**：「进行优化实施推进」→ 「把审批从 2 天降到 4 小时」
- **逻辑连接词过密**：「因此」「此外」「同时」「然而」连续出现 → 删掉，让逻辑自己说话
- **语义重复**：同一意思换三种说法 → 只保留最有力的那一种
- **句子太满**：一个句子塞了太多定语、括号、并列项 → 拆成两句

## 与 garron-writing-style 的关系

- `garron-writing-style` 是写作「宪法」，规定怎么写
- `garron-de-ai-writer` 是「去油」工序，检查写出来的东西有没有 AI 味
- 执行顺序：写初稿 → L1-L4 自检 → **去 AI 味** → 存档

## 特别注意（Garron 专属）

1. **不要抹掉 Garron 的个人特质**：他喜欢顿号列举、括号补充、中英混用，这些不是 AI 味，是他的表达习惯，保留
2. **不要把文学性磨平**：「加密通讯」系列追求的是文学随笔体，不是商业报告。感性段落的节奏不要被「信息密度」规则误杀
3. **区分「AI 味」和「个人风格」**：学术引用、框架分析是 Garron 的特色，不是 AI 腔。关键是引用方式——「德鲁克说过」比「管理学大师德鲁克曾经指出」更自然
