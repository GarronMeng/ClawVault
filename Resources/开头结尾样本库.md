# 开头结尾样本库

文章最容易坏在两个地方：

1. 开头太正确，读者进不来；
2. 结尾太总结，情绪落不住。

这个文件用来积累开头和结尾样本，让写作系统可以不断校准“怎么进入”和“怎么收束”。

---

## 1. 开头的目标

开头不是解释背景，而是让读者进入一个问题。

好的开头应该满足至少两个条件：

- 有画面；
- 有冲突；
- 有反常识；
- 有隐痛；
- 有一个读者想继续追问的问题。

不要一上来就写：

```text
随着 AI 技术的发展……
在当今社会……
最近我一直在思考一个问题……
```

除非后面马上给出非常具体的场景。

---

## 2. 开头类型库

### 2.1 隐痛切入型

适合：创作者、成长、关系、职业选择、长期焦虑。

结构：

```text
某类人有一个隐秘的痛苦：
他们能看见 X，
但无法轻易做到 Y。
```

检查：

- 这个痛苦是不是具体？
- 是否真的很少被说出口？
- 后文是否能解释它，而不是消费它？

样本：

```text
审美高的人有一个隐秘的痛苦：他们看得见别人看不见的东西，却总觉得自己的手够不着它。
```

---

### 2.2 具体场景型

适合：工作现场、公益实践、医疗运营、AI 工具使用。

结构：

```text
时间 / 地点 / 人物 / 动作 / 不对劲之处。
```

写法：

- 不急着解释意义；
- 不要先抛理论；
- 先让读者看到事情发生。

样本占位：

```text
[待补充]
```

---

### 2.3 荒诞事实型

适合：行业观察、财经热点、社会现象。

结构：

```text
先扔出一个反常事实。
然后问：为什么会这样？
```

样本占位：

```text
[待补充]
```

---

### 2.4 自问自答型

适合：思辨随笔、个人反思、社会观察。

结构：

```text
X 最可怕的是什么？
不是 A，是 B。
```

注意：

- B 必须真的比 A 更意外；
- 不能为了反转而反转；
- 问题要尖锐，不要泛泛。

样本：

```text
四分之一人生危机最可怕的部分是什么？不是崩溃，是不崩溃。
```

---

### 2.5 并置画面型

适合：朋友圈随笔、城市观察、代际变化、生活状态。

结构：

```text
把几个有张力的物品 / 场景摆在一起。
不解释。
让读者自己感受到冲突。
```

操作要领：

- 具体到品牌、型号、材质、颜色；
- 新旧之间要有张力；
- 最后一个物件可以出其不意；
- 列完就停，不要解释“这说明了”。

---

## 3. 结尾的目标

结尾不是总结，而是落点。

好的结尾应该做到：

- 与开头回环；
- 和全文能量一致；
- 留下一个感性锚点；
- 不突然鸡汤；
- 不突然喊口号；
- 不另起炉灶。

---

## 4. 结尾类型库

### 4.1 选择权落点

适合：AI、技术、职业、关系、社会结构。

结构：

```text
世界 / 系统 / 技术无法完全改变，
但人仍然保留某种选择权。
```

注意：

- 不是“相信自己”；
- 不是“勇敢做自己”；
- 必须具体说明选择权在哪里。

---

### 4.2 判断力落点

适合：复杂系统、管理、医疗运营、公益咨询。

结构：

```text
真正重要的不是有没有工具 / 资源 / 方法，
而是是否还能判断：
什么值得做，什么不值得做。
```

---

### 4.3 具体人落点

适合：公益、医疗、无障碍、真实个案。

结构：

```text
最后回到一个具体的人。
不要回到宏大愿景。
```

注意：

- 不要替对象煽情；
- 不要消费苦难；
- 具体的人比抽象的人群更有力。

---

### 4.4 安静余震型

适合：个人随笔、关系、审美、成长。

结构：

```text
说完判断后，留一个画面。
让读者自己停在那里。
```

## 5. 结尾能量检查表

| 检查项 | 是 / 否 |
|---|---|
| 结尾是否还在回答开头的问题？ |  |
| 结尾是否突然变成鸡汤？ |  |
| 结尾是否突然变得激进？ |  |
| 结尾是否只是在总结全文？ |  |
| 结尾是否有一个具体画面 / 选择 / 判断？ |  |
| 把结尾单独读一遍，像不像同一个人写的？ |  |

---

## 6. 新样本入库规则

每次 Writing Review 后，如果开头或结尾有效，就追加到这里。

格式：

```markdown
## 样本：文章标题

- 类型：开头 / 结尾
- 文章类型：
- 原文：
- 为什么有效：
- 可复用结构：
- 不能滥用的地方：
```
