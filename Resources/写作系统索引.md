# 写作系统索引

这不是一份普通的写作说明，而是 ClawVault 里所有写作能力的入口地图。

核心目标：把 Garron 的观察、情绪、判断和经验，稳定转化为可发布、可复盘、可迭代的文章。

---

## 1. 目标函数

写作系统要优化的不是单篇文章的漂亮程度，而是长期输出的复利：

```text
好文章 = 真实体感 × 非共识洞察 × 清晰结构 × 活人表达 × 可复盘迭代
```

其中：

- **真实体感**：来自 Garron 的一线经历、关系、工作现场、公益实践、技术折腾；
- **非共识洞察**：不是大家都会点赞的正确废话，而是能让人停顿、争论、重新理解问题的观点；
- **清晰结构**：不是 PPT 式罗列，而是有叙事弧线、逻辑升番和情绪落点；
- **活人表达**：像一个真实的人在认真说话，而不是模型生成的正确段落；
- **可复盘迭代**：每篇文章都沉淀选题、论点、素材、反馈和下一轮改进。

---

## 2. 系统边界

### 这个系统负责

- 从日常素材中发现选题；
- 用追问挖出真实论点；
- 按文章类型搭结构；
- 写出符合 Garron 风格的初稿；
- 清理 AI 味；
- 存档与复盘。

### 这个系统不负责

- 替 Garron 伪造第一手经历；
- 替 Garron 决定最终立场；
- 把所有文字打磨成同一种“高级感”；
- 为了传播牺牲真实判断；
- 用空泛金句掩盖论点不成立。

---

## 3. 写作控制回路

```text
输入素材
  → 选题评分
    → 洞察挖掘
      → 结构设计
        → 初稿生成
          → 四层自检
            → 去 AI 味
              → 发布 / 存档
                → 反馈复盘
                  → 更新方法论
```

| 环节 | 控制目标 | 对应文件 |
|---|---|---|
| 输入素材 | 保留现场感，不急着观点化 | `Daily Notes/`、`Templates/Daily Note.md` |
| 选题评分 | 判断值不值得写、什么时候写 | `.hermes-skills/writing/garron-topic-engine/SKILL.md` |
| 洞察挖掘 | 找到非共识论点 | `.hermes-skills/writing/garron-insights-deepdive/SKILL.md` |
| 结构设计 | 明确文章类型和情绪曲线 | `.hermes-skills/writing/garron-writing-style/SKILL.md` |
| 初稿生成 | 根据风格系统写出完整稿 | `.hermes-skills/writing/garron-writing-style/SKILL.md` |
| 去 AI 味 | 清理套路句、空转句和机械节奏 | `.hermes-skills/writing/garron-de-ai-writer/SKILL.md` |
| 反馈复盘 | 把反馈转成下一轮控制参数 | `Templates/Writing Review.md` |

## 4. 四个核心 Skill

### 4.1 选题引擎

文件：`.hermes-skills/writing/garron-topic-engine/SKILL.md`

触发语：

- “不知道写什么”
- “帮我选题”
- “最近有什么可以写的”
- “想写但没灵感”

输出：

- 候选选题；
- 角度 A/B/C；
- 世界观坐标；
- 体感强度、非共识度、信息增量、受众匹配、时机评分；
- 下一步建议。

### 4.2 洞察深挖

文件：`.hermes-skills/writing/garron-insights-deepdive/SKILL.md`

触发语：

- “我想写一篇关于 XX 的文章”
- “帮我挖掘一下这个主题”
- “还没想好怎么写”

输出：

- 5-8 个苏格拉底式追问；
- 核心洞察；
- 论点切入点；
- 红军压力测试；
- 文章架构。

### 4.3 写作风格系统

文件：`.hermes-skills/writing/garron-writing-style/SKILL.md`

触发语：

- “帮我写文章”
- “按这个大纲写”
- “写成 Garron 风格”
- “写公众号 / 随笔 / 行业观察 / 公益实践”

核心约束：

- 内容内核先行；
- 先给画面和冲突，再给观点；
- 现实的理想主义者；
- 升番，而不是机械递进；
- 结尾必须能量一致；
- 最终创意决策由人完成。

### 4.4 去 AI 味

文件：`.hermes-skills/writing/garron-de-ai-writer/SKILL.md`

触发语：

- “去 AI 味”
- “帮我润色成更像我写的”
- “写完了，过一遍”

处理：

- 禁用词扫描；
- 英文备注清理；
- 套路句式检查；
- 信息密度检查；
- 标点节奏修正；
- 段落结构检查；
- 语感终审。

## 5. 可控变量与反馈指标

| 变量 | 如何控制 | 反馈指标 |
|---|---|---|
| 选题强度 | 体感强度 × 非共识度 × 信息增量 | 是否让人想转发 / 争论 / 私聊 |
| 论点锋利度 | 用红军模式反复质疑 | 是否能用一句话说清楚 |
| 结构清晰度 | 先选文章原型，再写大纲 | 读者是否能跟上情绪和逻辑曲线 |
| 活人感 | 保留具体场景、自嘲、口语暗门 | 是否像真实的人写的 |
| AI 味 | 必须过 de-ai-writer | 是否有套路句、空转句、机械排比 |
| 复盘质量 | 每篇文章填写 Writing Review | 下次是否能明确改一个参数 |

---

## 6. 最小可运行闭环

当 Garron 说“我想写点东西”时，Agent 按下面顺序判断：

```text
没有主题？
  → 启动 topic-engine

有主题但没论点？
  → 启动 insights-deepdive

有论点和素材？
  → 启动 writing-style

初稿完成？
  → 启动 de-ai-writer

发布或存档后？
  → 填写 Writing Review
```
