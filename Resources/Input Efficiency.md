# 高效输入处理指南

## 🎯 原则
1. **快速捕获**：不打断当前工作
2. **标签先行**：用 `#标签` 快速分类
3. **批量处理**：统一时间整理
4. **原子记录**：每条信息独立，便于重组

## 📝 输入格式
```
[标签] 简短内容
```
例：
```
#想法 自动化是否真的能取代人的温度？
#任务 完成 OpenClaw 文档阅读
#学习 Obsidian 插件开发
```

## ⚡ Token 节省
- 避免长句重复，用引用或链接
- 我来做摘要，你只需给原始素材
- 批量发送多段内容，减少往返

## 🔄 处理流程
1. 你随时发送文本/语音转文字
2. 我分类到 Daily Note 的相应部分
3. 周末自动提取 Projects/Areas 的更新
4. 月底生成月度回顾

## 🛠️ 工具
- Telegram → 即时捕获
- Obsidian → 长期存储与链接
- OpenClaw → 自动化处理
