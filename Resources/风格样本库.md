# 风格样本库

这个文件用来沉淀 Garron 自己认可的表达样本。

目标是帮助 Agent 区分：

- 什么是个人风格；
- 什么是 AI 味；
- 什么是可以复用的结构；
- 什么只是某一篇文章里的临时表达。

---

## 1. 使用原则

### 可以学习

- 开头如何进入现场；
- 如何把概念递给读者；
- 如何把严肃判断写得不端着；
- 如何在结尾保留能量；
- 如何用具体细节替代抽象情绪。

### 避免机械复刻

- 不要每篇都写成同一种节奏；
- 不要把短句独立成段当万能技巧；
- 不要每篇都塞自嘲；
- 不要把金句当文章骨架；
- 不要为了像某种风格而牺牲具体内容。

## 3. 开头样本

### 3.1 隐痛切入型

适合主题：审美、焦虑、成长、选择、创作者困境。

结构：

```text
某类人有一个很少被说出口的感受：
他们能看见 X，
但无法轻易做到 Y。
```

适用条件：

- 读者真的有类似感受；
- 不是为了煽情；
- 后文能提供更深的解释。

### 3.2 具体场景型

适合主题：工作现场、公益实践、医疗管理、AI 工具使用。

结构：

```text
先给一个具体时刻。
不要解释意义。
让读者先看到人、物、动作和冲突。
```

检查：

- 有没有地点？
- 有没有人物？
- 有没有具体动作？
- 有没有一个不对劲的地方？

### 3.3 荒诞事实型

适合主题：行业观察、社会现象、热点解读。

结构：

```text
先抛一个违反直觉的事实。
不要马上解释。
让读者产生“怎么会这样”的感觉。
```

## 4. 中段样本

### 4.1 知识是递上去的

低效写法：

> 这让我想起了某某理论。

更好的方式：

> 先写读者已经看见的问题，再把理论作为解释工具递上去。

判断标准：

- 理论出现前，读者是否已经需要它？
- 删掉理论后，文章是否还成立？
- 理论是否帮文章往前走，而不是显得作者懂很多？

### 4.2 升番而不是罗列

每一层都要比上一层多一点东西：

1. 第一层：读者已经知道，但没说清楚；
2. 第二层：读者隐约感受到，但没意识到；
3. 第三层：读者没想到，或者不愿意承认；
4. 第四层：回到作者自己的判断。

---

## 5. 结尾样本

### 5.1 感性锚点

结尾不是总结，而是落点。

好的结尾应该让读者感觉：

- 逻辑已经结束；
- 情绪还停留在一个准确的位置；
- 有一句话可以带走；
- 但不是鸡汤。

### 5.2 能量一致性

| 正文能量 | 结尾落点 |
|---|---|
| 深刻内省 | 安静但有余震 |
| 社会批判 | 保持力度，但不喊口号 |
| 技术反思 | 落到人的选择权和判断力 |
| 公益实践 | 落到具体的人，而不是宏大愿景 |
| 朋友圈随笔 | 回到连接和感谢，但不廉价煽情 |

## 6. 句子样本

### 像 Garron 的句子特征

- 有判断，但不急着摆出权威姿态；
- 有概念，但概念背后有真实体感；
- 有自嘲，但自嘲不是装可爱；
- 有锋芒，但不是喊口号；
- 有文学性，但不牺牲信息密度。

### 不像 Garron 的句子特征

- 过度工整；
- 过度正确；
- 过度宏大；
- 过度总结；
- 过度像公众号模板。

---

## 7. 新样本入库规则

每次写完一篇文章，如果有值得复用的表达，在 Writing Review 里标记，并同步到这里。

入库格式：

```markdown
## 样本：文章标题

- 类型：
- 可复用点：
- 原句 / 原段：
- 为什么有效：
- 不能滥用的地方：
```
