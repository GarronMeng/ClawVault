# 风格样本库

这个文件用来沉淀 Garron 自己认可的表达样本。

目标是帮助 Agent 区分：

- 什么是个人风格；
- 什么是 AI 味；
- 什么是可以复用的结构；
- 什么只是某一篇文章里的临时表达。

---

## 1. 使用原则

### 可以学习

- 开头如何进入现场；
- 如何把概念递给读者；
- 如何把严肃判断写得不端着；
- 如何在结尾保留能量；
- 如何用具体细节替代抽象情绪。

### 避免机械复刻

- 不要每篇都写成同一种节奏；
- 不要把短句独立成段当万能技巧；
- 不要每篇都塞自嘲；
- 不要把金句当文章骨架；
- 不要为了像某种风格而牺牲具体内容。

## 3. 推进机制样本

### 3.1 隐痛 → 场景 → 机制

来源：[[审美是创作者的诅咒]]

**原文片段：**

> 审美高的人有一个隐秘的痛苦：他们看得见别人看不见的东西，却总觉得自己的手够不着它。
>
> 香港艺术馆，一幅崖洞派对的画。火光映着岩壁，一群赤脚的人在跳舞。我盯着它看了很久，脑子里突然冒出一个画面——《挽救计划》里，Grace 在给外星人 Rocky 上课。

**为什么有效：**

| 维度 | 分析 |
|---|---|
| 进入方式 | 先给隐痛，再给艺术馆场景，不是直接讲“创作者焦虑” |
| 具体性 | 香港艺术馆、崖洞派对、火光、岩壁、Grace 和 Rocky 都是具体物件 |
| 机制 | 后文把“写不出来”转成“发不出去”，完成从情绪到机制的提炼 |
| 风格 | 有画面、有跨文本连接、有自我暴露，但不撒娇 |

**可复用结构：**

```text
某类人有一个隐秘痛点
→ 一个具体场景触发它
→ 我想表达但卡住
→ 重新定义问题不是 X，而是 Y
```

**不能滥用：**

- 不能每篇都从“某类人有一个隐秘痛苦”开始；
- 只有当后文真的有具体场景和机制提炼时才成立；
- 如果没有真实体验，会迅速变成伪深刻开头。

---

### 3.2 自问自答 → 身体体感 → 结构压力

来源：[[加密通讯]]

**原文片段：**

> 四分之一人生危机最可怕的部分是什么？
>
> 不是崩溃，是不崩溃。
>
> 不是你突然撑不住了，而是你发现自己已经很久没有因为什么事真正生气、真正难过、真正开心过了。

**为什么有效：**

| 维度 | 分析 |
|---|---|
| 反转 | 常识以为危机是崩溃，文章反过来说“不崩溃”更可怕 |
| 体感 | 用“很久没有真正生气、难过、开心”把抽象危机落到身体经验 |
| 推进 | 后文从个人麻木推进到公共危机、技术变化和选择权 |
| 节奏 | 两个短问答建立节奏，第三段展开具体含义 |

**可复用结构：**

```text
X 最可怕的是什么？
不是 A，是 B。
B 不是一个观点，而是一种身体 / 行为上的变化。
```

**不能滥用：**

- “不是 A，是 B”必须真的有反直觉；
- 不要为了句式而反转；
- 后文必须接真实体感，否则像标题党。

---

### 3.3 工具经验 → 暴露问题 → 判断力上升

来源：[[当AI学会替你动手/01-效率的幻觉]]

**原文片段：**

> 今天这篇文章，写于一个 AI Agent 的帮助之下。
>
> 准确地说，是它帮我从 21 篇 HTML 文件中提取了文本、分析了文风、整理了主题框架，然后我坐在这些素材上面，试图写出一篇「像我写的」东西。这个过程本身就构成了这篇文章最好的引子。

**为什么有效：**

| 维度 | 分析 |
|---|---|
| 进入方式 | 从真实工具使用进入，不从“AI 时代”宏大背景进入 |
| 具体性 | 21 篇 HTML、提取文本、分析文风、整理框架，动作清晰 |
| 反转 | 工具提高效率后，真正暴露的是“我是否真的在思考” |
| 适用主题 | 技术、Agent、自动化、效率工具、工作方法 |

**可复用结构：**

```text
我用一个工具完成了具体任务
→ 它确实提高了效率
→ 但真正震动我的不是效率
→ 而是它暴露了过去被忙碌掩盖的问题
```

**不能滥用：**

- 不要写成工具测评；
- 工具只是引子，真正的文章对象是人和判断；
- 如果没有“暴露了什么”，就只是效率炫耀。

---

### 3.4 专业概念 → 真实案例 → 边界判断

来源：[[当AI学会替你动手/03-手感的消亡]]

**原文片段：**

> 我认识一些资深咨询顾问，他们之所以能在客户面前一针见血，不是因为掌握了什么秘密模型，而是因为十年如一日地「泡」在行业里，积累了大量无法被结构化描述的隐性知识。
>
> 这种知识不在任何数据库里，不在任何框架图上，它存在于你反复试错的身体记忆和直觉判断之中。

**为什么有效：**

| 维度 | 分析 |
|---|---|
| 概念引入 | 不先定义“隐性知识”，而是先写资深顾问的表现 |
| 具体机制 | 把“手感”解释为反复试错后的身体记忆和直觉判断 |
| 边界 | 后文区分“替代性使用”和“增强性使用”，避免简单反 AI |
| 风格 | 有专业框架，但不是咨询报告腔 |

**可复用结构：**

```text
先写一个高手的现场表现
→ 指出这不是模型，而是长期积累的手感
→ 放入一个新工具冲击场景
→ 区分替代性使用和增强性使用
```

**不能滥用：**

- 不要把“隐性知识”写成概念科普；
- 技术文章要有真实工作场景；
- 结论要有边界，避免简单“工具好/工具坏”。

---

### 3.5 荒诞并置 → 结构不安 → 权利问题

来源：[[当康复被写进国家标准]]

**原文片段：**

> 我扫了一眼清单：民用无人机、烟花爆竹、家用咖啡机、鞋长。然后在第六条停住了——孤独症儿童康复机构服务质量。
>
> 烟花爆竹和孤独症康复在同一张清单上。一个是节日的噪音，一个是沉默的日常。

**为什么有效：**

| 维度 | 分析 |
|---|---|
| 进入方式 | 从清单里的荒诞并置进入，而不是直接讲政策意义 |
| 情绪曲线 | 先松一口气，再浮现不安，避免单向度赞美或批评 |
| 结构推进 | 从国标推进到“谁定义好”的权利问题 |
| 公益视角 | 不消费个体苦难，而是讨论标准、参与和定义权 |

**可复用结构：**

```text
一个公共文件 / 新闻清单里的反常并置
→ 我先产生一种直觉反应
→ 另一种不安浮上来
→ 问题从“有没有”转成“谁定义”
```

**不能滥用：**

- 不要写成政策解读；
- 不要替服务对象发言，要强调 voice 是否在场；
- 需要具体个体经验作为落点。

## 4. 句子样本

### 4.1 像 Garron 的句子特征

- 有判断，但不急着摆出权威姿态；
- 有概念，但概念背后有真实体感；
- 有自嘲，但自嘲不是装可爱；
- 有锋芒，但不是喊口号；
- 有文学性，但不牺牲信息密度。

### 4.2 可复用句子机制

| 来源 | 句子 / 片段 | 机制 | 风险 |
|---|---|---|---|
| 审美 | “审美的觉醒往往早于能力的成熟。” | 把创作焦虑从性格问题转成时间差问题 | 容易被滥用成金句 |
| 审美 | “完美主义不是通往完美的路，是通往沉默的路。” | 否定前置 + 反向定性 | 如果没有前文铺垫会显得鸡汤 |
| 加密通讯 | “你不能选择性地麻木——要么全开，要么全关。” | 把心理状态写成系统开关 | 注意破折号使用，正式稿可改句号 |
| 加密通讯 | “感受力不是脆弱。是你还拥有选择权的证据。” | 重新定义概念，落到主体性 | 容易被模仿成抽象金句 |
| 效率的幻觉 | “当执行的成本趋近于零，思考的价值反而趋近于无穷。” | 技术变化 → 人的稀缺能力 | 需要前文工具场景支撑 |
| 手感的消亡 | “如果你从未在某个领域笨拙过、犯错过、痛过，你就不可能在那个领域拥有真正的手感。” | 成长代价的三联推进 | 不要变成励志训诫 |
| 国标 | “标准是不完美的底线。但没有底线就是深渊。” | 双重判断，既承认价值也指出限制 | 需要避免二元绝对化 |

---

## 5. 不像 Garron 的句子特征

- 过度工整；
- 过度正确；
- 过度宏大；
- 过度总结；
- 过度像公众号模板；
- 只有主体性、结构、异化等词，没有具体人和具体动作。

---

## 6. 新样本入库规则

每次写完一篇文章，如果有值得复用的表达，在 Writing Review 里标记，并同步到这里。

入库格式：

```markdown
## 样本：文章标题

- 类型：
- 可复用点：
- 原句 / 原段：
- 为什么有效：
- 不能滥用的地方：
```
