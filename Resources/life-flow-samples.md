# 生活流样本库

这个文件专门保存 Garron 在朋友圈、旅行记录、日常观察中的“自然语流”。

它的作用不是制造文学感，而是纠正 AI 常见的高级写作误区：

- 一句一段；
- 强行留白；
- 每句话都想当金句；
- 过早升维；
- 没有现场就开始讲道理。

Garron 的生活流文字更像：

```text
现场细节自然铺开
→ 多种事物并置
→ 感受慢慢浮出来
→ 判断后置
→ 结尾保留一点余味
```

## 1. 样本：斯米兰 / 净滩

### 原文

> 听当地向导说斯米兰要封岛养护生态15年，于是踩着倒计时终于看到了果冻海和晚霞。
> 可惜原本属于这里的海龟，因为人类活动和污染已经鲜少露面，痛心之余也想做些什么。
> 回到深圳，有幸参与MCF组织的月捐人净滩活动，比起洋流和航洋活动带来的10%垃圾，40公斤里面绝大部分还是来自陆地活动。了解到从源头减塑、绿色焚烧到科技打捞，希望有机会探索更多可能性。

### 类型

旅行现场 → 缺失感 → 低姿态行动 → 公共议题入口

### 为什么有效

| 维度 | 分析 |
|---|---|
| 现场 | 斯米兰、封岛、果冻海、晚霞，先让读者进入具体旅行现场 |
| 缺失 | 海龟“不再露面”比直接讲环保更有痛感 |
| 行动 | “痛心之余也想做些什么”是低姿态行动，不是道德表演 |
| 数据 | 10%、40公斤、陆地活动，让行动有现实重量 |
| 开口 | 结尾是“探索更多可能性”，不是号召别人 |

### 可复用结构

```text
听到一个现场信息
→ 趁着某个时间窗口去看见具体风景
→ 看见一个已经消失 / 正在消失的东西
→ 产生有限但真实的行动
→ 回到本地，把行动接到一个更大的议题
→ 以探索而不是宣言收束
```

### 风格指纹

- 不直接说“保护环境很重要”；
- 先写看见了什么，再写没看见什么；
- 行动表达克制，不把自己放在道德高位；
- 公共议题通过具体数字和具体活动进入；
- 结尾保留“探索更多可能性”的开放感。

### 不能滥用

- 不要每次旅行都强行接公益行动；
- 不要把“痛心之余”写成固定套话；
- 如果没有真实参与，不要补一个行动结尾；
- 不要把这类文案写成公益组织宣传稿。

## 2. 样本：曼谷 / 热带无哲学

### 原文

> 曼谷真的好神奇，氤氲暧昧的水汽恰似文化模糊的界限，连电影里的侨胞和吉姆汤普森这种外国人都被同化了暹罗风味，遑论融合印泰风味的咖喱与疑似广西的芒果糯米饭。这里有天铁、地铁、摩的、巨幅广告牌、爵士乐酒吧，也有伦披尼蜥蜴、湿婆像和朱拉隆功学生批判时政的毕业设计。
> 所有的一切在这里交织，像丝绸般滑过却不留痕迹。“热带无哲学”，于是我放弃了思考，只是感受。此时天上一大束气球飞掠而去——也许这就是放空的意外之喜。

### 类型

城市观察 → 文化并置 → 放弃解释 → 感受收束

### 为什么有效

| 维度 | 分析 |
|---|---|
| 长呼吸 | 第一段是长句推进，不是一句一段，保留真实观察的流动感 |
| 并置 | 天铁、地铁、摩的、广告牌、爵士乐酒吧、蜥蜴、湿婆像、毕业设计并置，读者自己感到曼谷的混杂 |
| 感官 | 水汽、暧昧、丝绸、气球，让城市不是概念而是触感 |
| 判断后置 | “热带无哲学”在大量现场之后出现，因此不像空洞金句 |
| 余味 | 气球飞掠是偶然画面，提供轻盈收束 |

### 可复用结构

```text
先给一个整体感受
→ 用长句把不同文化、交通、食物、人物、动物、公共空间并置
→ 不急着解释城市意义
→ 让一个判断从现场里长出来
→ 用偶然画面收尾
```

### 风格指纹

- 用并置代替解释；
- 不怕长句，允许观察自然堆叠；
- 判断不是开头的论点，而是后半段自然浮出的感受；
- 城市不是“现代与传统交织”这种概念，而是天铁、摩的、蜥蜴、湿婆像、毕业设计这些具体物；
- 结尾可以轻，不必把意义收满。

### 不能滥用

- 不要把所有旅行文都写成“城市真神奇”；
- “热带无哲学”这类句子只能在具体细节足够密之后出现；
- 不要把并置写成景点清单，物件之间必须有文化张力；
- 不要在结尾强行升华成旅行意义。

## 3. 生活流写作规则

### 3.1 先让现场自己说话

不要一上来解释意义。

低效写法：

```text
这次旅行让我意识到生态保护的重要性。
```

更像 Garron：

```text
听当地向导说斯米兰要封岛养护生态15年，于是踩着倒计时终于看到了果冻海和晚霞。
```

---

### 3.2 用并置代替概括

低效写法：

```text
曼谷是一个传统与现代交织的城市。
```

更像 Garron：

```text
这里有天铁、地铁、摩的、巨幅广告牌、爵士乐酒吧，也有伦披尼蜥蜴、湿婆像和朱拉隆功学生批判时政的毕业设计。
```

---

### 3.3 判断要后置

不要过早写：

```text
真正重要的是感受。
```

应该先铺现场，再让判断自然浮出：

```text
所有的一切在这里交织，像丝绸般滑过却不留痕迹。“热带无哲学”，于是我放弃了思考，只是感受。
```

---

### 3.4 行动要克制

低效写法：

```text
希望大家都能一起保护海洋。
```

更像 Garron：

```text
痛心之余也想做些什么。
```

## 4. 生活流 anti-pattern

| 问题 | 表现 | 修正 |
|---|---|---|
| 过度短句 | 一句一段，像 AI 在制造节奏 | 合并成自然长句 |
| 过早升维 | 还没写现场就开始讲意义 | 先写物、人、动作、天气、声音 |
| 公益宣传腔 | “希望大家一起……” | 写自己做了什么、看见什么、还不确定什么 |
| 景点清单 | 只列地点，没有关系 | 选择有张力的物件并置 |
| 金句先行 | 开头就抛判断 | 判断后置，让它从现场里长出来 |

---

## 5. 给 Agent 的调用提示

当用户要写朋友圈、旅行记录、日常观察时：

1. 优先读取本文件，而不是只读取 `garron-writing-style`；
2. 默认使用长呼吸段落，不要一句一段；
3. 先保留现场，再补判断；
4. 判断只能出现一次，不要每段都总结；
5. 结尾允许轻，允许开放，不要强行升华。
