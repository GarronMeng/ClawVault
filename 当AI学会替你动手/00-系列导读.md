# 当 AI 学会替你「动手」— 系列导读

> 一组关于 AI Agent 实践的深度随想，写于密集使用 Hermes Agent 30 天之后。
> 不是技术教程，而是一个人的思考笔记：当机器越来越像人，人该像什么？

## 系列脉络

```
效率的幻觉 → 权力转移 → 手感的消亡 → 公益遇上Agent → 共创的边界
   （内）        （外）        （代价）        （实践）         （反思）
```

从**个人体验**出发（效率焦虑），推向**社会结构**分析（权力关系），再深入**能力代价**的隐忧（隐性知识），落地到**公益实践**的真实场景，最终回归**创作伦理**的自我追问。

## 五篇文章

### [[01-效率的幻觉|一、效率的幻觉]]
**核心问题：** Agent 暴露了什么？
- 效率 vs 效能的经典区分
- 当「搬运工」的活被替代，你拿省下的时间做了什么？
- 判断力是最古老也最稀缺的能力

### [[02-权力转移|二、权力转移]]
**核心问题：** 权力关系变了吗？
- Structure-Agent 框架下的微观权力转移
- 从「用户」到「委托者」的语义跃迁
- MCP / A2A 协议正在铺路

### [[03-手感的消亡|三、手感的消亡]]
**核心问题：** 我们在失去什么？
- 隐性知识（tacit knowledge）与认知萎缩
- GPS 让人类丧失空间记忆，Agent 会让我们丧失什么？
- 「替代性使用」vs「增强性使用」的边界

### [[04-公益遇上Agent|四、公益遇上 Agent]]
**核心问题：** Agent 能解决公益的痛点吗？
- 桌面研究从 2 天缩短到 35 分钟的真实案例
- Agent 是「基础设施层」，但不能替代需求发现
- 「Nothing about us without us」在 Agent 时代的含义

### [[05-共创的边界|五、共创的边界]]
**核心问题：** 谁在写这篇文章？
- AI 辅助写作的诚实交代
- 「审美主权」的概念：你能否分辨「这像不像我」？
- 30% 原样保留 vs 40% 大幅修改的实验数据

## 写作方法

这组文章的创作流程：
1. **素材输入：** 21 篇历史文章 → 文风分析（主题偏好、论证习惯、语言特征）
2. **AI 初稿：** Agent 生成「像我写的」初稿
3. **人工打磨：** 修改比例约 70%（大幅修改 40% + 小幅调整 30%）
4. **结构设计：** 每篇固定三段式 — ✏️主题正文 → ☀️加隆动态 → ☉️加思时刻
