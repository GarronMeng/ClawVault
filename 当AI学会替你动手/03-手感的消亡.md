# 手感的消亡：隐性知识会被 Agent 蚕食吗？

✏️ 当 AI 学会替你「动手」（三）

我认识一些资深咨询顾问，他们之所以能在客户面前一针见血，不是因为掌握了什么秘密模型，而是因为十年如一日地「泡」在行业里，积累了大量无法被结构化描述的隐性知识。

这种知识不在任何数据库里，不在任何框架图上，它存在于你反复试错的身体记忆和直觉判断之中。一个老练的审计师翻两页报表就知道哪里有问题，一个资深的产品经理看一眼用户反馈就知道该优先处理什么，一个经验丰富的社工听三句话就能判断求助者真正的需求是什么。

如果年轻一代从一开始就依赖 Agent 完成「脏活累活」，他们还能发展出这种手感吗？

这就像 GPS 导航让人类丧失了空间记忆能力一样——工具的便利，可能是能力的慢性毒药。伦敦出租车司机的研究早就证明，长期依赖导航会导致海马体（负责空间记忆的脑区）萎缩。那么，长期依赖 Agent 做分析、做检索、做整理，我们的「认知海马体」会不会也跟着萎缩？

我在自己的公益咨询工作中已经开始重度依赖 Agent 了。上周帮一个无障碍项目做利益相关方分析，Agent 帮我在 20 分钟内跑完了过去需要两天的桌面研究，包括政策梳理、竞品对标、用户画像初稿。这让我有更多时间去做真正需要「人」的部分——跟残障伙伴深度访谈，理解那些数据永远捕捉不到的微妙处境。

所以问题不在于「该不该用 Agent」，而在于「用 Agent 腾出来的时间，你拿去干什么了」。

如果你用省下来的时间去刷短视频、去消磨、去享受「终于不用干活了」的快感——那 Agent 确实在蚕食你的能力。但如果你用省下来的时间去做更高层次的事情：思考战略、建立关系、深化理解、培养直觉——那 Agent 就是你最好的磨刀石。

这里有一个关键的区分：「替代性使用」和「增强性使用」。前者是让 Agent 代替你思考，后者是让 Agent 代替你执行，从而释放你的思考空间。两者的边界有时候很模糊，但后果天差地别。

---

> ☀️ **加隆动态**
>
> 今天跟一位做 RPA的朋友聊天，他说了一句很精辟的话：「最好的自动化，是让人类去做只有人类能做的事情。」我补了一句：「但前提是，你得先搞清楚哪些是只有人类能做的事情。」
>
> 这可能才是 Agent 时代最值得每个人花时间思考的问题。

---

> ☉️ **加思时刻（Just Moment）**
>
> 技艺的精进从来不是从舒适区里长出来的，而是从反复的挫败和修正中磨出来的。如果你从未在某个领域笨拙过、犯错过、痛过，你就不可能在那个领域拥有真正的「手感」。Agent 可以帮你跳过笨拙的阶段，但也可能同时跳过了你成长的机会。
