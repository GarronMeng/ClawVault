# ClawVault

你的个人知识库，由 OpenClaw 助手维护。

## 📂 结构
- **Daily Notes/**：每日日记，按日期命名
- **Projects/**：进行中的项目，每个项目独立笔记
- **Areas/**：责任领域（职业、健康、家庭等）
- **Resources/**：参考资料、模板、方法库
- **Archives/**：归档旧笔记
- **Templates/**：模板文件

## 🚀 开始使用
1. 打开 Obsidian 桌面版
2. 选择 "Open folder as vault"
3. 浏览到 `~/Desktop/ClawVault` 并打开
4. 享受你的第二大脑

## 🔄 工作流
- **每日**：晚上总结，更新 Daily Note
- **每周**：用 Weekly Review 模板回顾
- **随想**：直接扔进 Daily Notes 的「随想」部分，周末整理

所有笔记支持双链 `[[...]]`，可以自由链接。
