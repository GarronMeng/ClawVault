## 9. 四层自检

### L1：硬规则

- [ ] 没有“总而言之 / 综上所述 / 毋庸置疑 / 显而易见”等 AI 腔
- [ ] 没有机械的“一方面 / 另一方面 / 首先 / 其次 / 最后”
- [ ] 没有无意义英文括注
- [ ] 没有用破折号和引号制造虚假强调

### L2：风格一致性

- [ ] 开头先给画面和冲突
- [ ] 论述有谦逊感，不像人生导师
- [ ] 长短句有变化
- [ ] 结尾能量与全文一致

### L3：内容质量

- [ ] 文章只有一个内容内核
- [ ] 每个故事都服务于内核
- [ ] 知识和框架是在需要时“递上去”的
- [ ] 读者能带走一个清晰判断

### L4：活人感

- [ ] 有真实细节
- [ ] 有对话感
- [ ] 有一处自嘲 / 暗门 / 具体画面
- [ ] 默读不像 AI 写的
